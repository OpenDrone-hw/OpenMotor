Validate: none

## Boundaries

- Variant specs in the README come from `OpenDrone/web/content/products/openmotor.json`: change them there first, then here.
- Write a QC verdict or measured value only from a real record in `test/`; never invent a result.
- Sourcing (suppliers, prices, quotes, RFQs, contacts) never lives in OpenDrone repositories.
